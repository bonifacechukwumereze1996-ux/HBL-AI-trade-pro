# HBL AI Trader Pro

HBL AI Trader Pro is a Streamlit-based AI trading dashboard designed to analyze live forex market data and generate trading signals using technical indicators.

## Features

- Live Forex Market Data
- AI Signal Analysis
- Technical Indicators (EMA, RSI, MACD, ADX)
- Interactive Candlestick Charts
- Telegram Signal Alerts
- Trade History
- Risk Management Dashboard
- Auto Refresh

## Technologies Used

- Python
- Streamlit
- yFinance
- Plotly
- Pandas
- TA Library

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
